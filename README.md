# 💻 Algoritmos II

Repositório de materiais e códigos utilizados na disciplina **Algoritmos II**, do **Instituto de Computação (IC)**.

Aqui serão disponibilizados os códigos desenvolvidos durante as aulas, exemplos, exercícios e outros materiais utilizados ao longo da disciplina.

---

## 📚 Conteúdo da disciplina

Ao longo da disciplina, serão abordados conceitos relacionados ao desenvolvimento de algoritmos e à programação utilizando a linguagem **C**, com ênfase na organização, manipulação e processamento de dados.

Entre os principais conteúdos estão:

* Funções e procedimentos
* Passagem de parâmetros
* Vetores e matrizes
* Algoritmos de ordenação
* Algoritmos de busca
* `struct` e tipos definidos pelo usuário (`typedef`)
* Ponteiros
* Alocação dinâmica de memória
* Estruturas de dados

## 🧑‍💻 Como utilizar os códigos

Os códigos deste repositório têm finalidade **didática** e foram desenvolvidos para acompanhar os conteúdos apresentados em sala de aula.

Para estudar, recomenda-se:

1. Leia o enunciado ou comentário presente no início do código.
2. Tente desenvolver sua própria solução antes de consultar a implementação disponível.
3. Compile e execute o programa.
4. Teste diferentes valores de entrada.
5. Modifique o código e observe como as alterações afetam o comportamento do programa.
6. Compare diferentes formas de resolver o mesmo problema.

> 💡 **Importante:** aprender programação envolve muito mais do que compreender um código pronto. Experimente, modifique, teste e desenvolva suas próprias soluções.

## 🛠️ Linguagem utilizada

Os exemplos da disciplina são desenvolvidos principalmente em **C**.

Exemplo:

```c
#include <stdio.h>

int main() {
    printf("Algoritmos II\n");

    return 0;
}
```

---

## ⚠️ Sobre os códigos

Os códigos disponibilizados neste repositório foram elaborados com finalidade educacional.

Em alguns casos, uma implementação pode priorizar a **clareza e a compreensão do algoritmo** em vez de apresentar a solução mais otimizada ou sofisticada possível.

Isso permite acompanhar gradualmente a evolução dos conceitos apresentados na disciplina.

---

## 📌 Recomendações

Durante os estudos:

* não se limite a copiar os códigos;
* tente resolver os exercícios antes de consultar as soluções;
* utilize o depurador (*debugger*) para acompanhar a execução dos programas;
* teste casos diferentes dos apresentados em aula;
* procure entender **por que** cada instrução está sendo utilizada;
* compare diferentes soluções para um mesmo problema.
